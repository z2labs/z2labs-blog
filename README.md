# Z2Labs blog (Hugo + GitHub Pages)

Static blog generated by [Hugo](https://gohugo.io) with the PaperMod theme and deployed by GitHub Actions to GitHub Pages. No CMS, no database: a post is a folder with `index.md` and its images.

## Write a post

```
content/posts/<slug>/
  index.md          # front matter + Markdown
  photo-1.jpg       # images next to the text, referenced as photo-1.jpg
```

Front matter (copy from `content/posts/hubble-xg24-satellite-test/index.md`):

```yaml
---
title: "Title with a number"
date: 2026-10-05
author: "Zoltán Dóczi"
slug: short-url-slug
description: "Meta description, under 155 characters."
tags: [sdr, esp32]
categories: [R&D]
cover: { image: hero.jpg, alt: "Alt text", relative: true }
math: true          # only if the post uses $...$ or $$...$$
---
```

Code blocks are fenced with a language (```powershell, ```c, ```text) and are rendered at build time: no JavaScript, no flicker. Images: `<figure>` with `<figcaption>` for a conclusion caption (see the Hubble post), or plain `![alt](file.jpg)`. Keep images at 2000 px or less.

## Preview locally

Install Hugo extended ≥ 0.158 (`winget install Hugo.Hugo.Extended` on Windows, `brew install hugo` on macOS), then:

```
hugo server -D
```

Open http://localhost:1313/z2labs-blog/. Drafts (`draft: true`) show locally and are not published.

## Publish

`git push` to `main`. The workflow in `.github/workflows/hugo.yml` builds the site and deploys it; it takes about a minute. Check the *Actions* tab if something does not appear.

## One-time GitHub setup

1. Create the repo (`z2labs/z2labs-blog`), push this folder.
2. Repo *Settings → Pages → Build and deployment → Source*: **GitHub Actions**.
3. Test URL: `https://z2labs.github.io/z2labs-blog/` (`baseURL` in `hugo.yaml` must match).
4. Custom domain later: *Settings → Pages → Custom domain* = `blog.z2labs.io`, add a `CNAME` DNS record pointing to `<org>.github.io`, and set `baseURL: https://blog.z2labs.io/`.

## Migrating the old Notion posts

Export each Notion page as *Markdown & CSV*, drop the `.md` into a new post folder as `index.md`, move its images next to it, add front matter, and fix image links to bare file names. Old URLs (`/article/<slug>`) can be preserved with `aliases: ["/article/<slug>"]` in the front matter.
