Radio performance benchmarking is a service we successfully provided on a number of occasions. The goal of such an exercise is to compare radio performance parameters between multiple silicon vendors. The final report is a very useful input to the decision-making process of selecting the components for next generation or new products.

We instrumentalise the devices and test them under the same conditions, even parallel for static and dynamic DC currents to receiver sensitivity and immunity to transmitter emission masks just to name a few key parameters. One of these projects resulted in a self-contained measurement setup for link budget tests on a proprietary radio protocol. Check it out below!
